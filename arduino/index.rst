Arduino
=======

SG Wireless F1 (ESP32-S3) modules are also available as an Arduino core, so
sketches can target them straight from the Arduino IDE — the CTRL client, the
LTE-M modem, LoRaWAN, the filesystem and the bundled examples — without checking
out the SDK or running its build system.

The pages below cover installing and using the released board-manager package,
and building that package yourself from the SDK sources. To build and flash the
Arduino examples through the SDK's ``fw_builder.sh`` flow, see
:doc:`/firmware-development`.
