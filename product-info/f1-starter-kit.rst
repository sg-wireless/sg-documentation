F1 Starter Kit
==============

.. TODO:: Migrate content from https://docs.sgwireless.com/product-info-datasheets/user-manual/

The F1 Starter Kit is a development platform for evaluating the F1 Smart Module.
It provides USB-C connectivity, onboard sensors, and easy access to all module
pins.

What's in the Box
-----------------

* F1 Smart Module on carrier board (SGW3501-F1-StarterKit)
* USB-C cable
* Quick start guide
