Integrations
============

Ctrl offers a way to interact with external platforms and services, including the
following:

- :doc:`Webhook <webhook>` -- allows for user-defined HTTP callbacks to a defined
  remote destination. All elements of the requests (headers, query string
  parameters, etc.) are customisable.
- :doc:`AWS IoT Core <aws-iot-core>` -- a managed cloud platform that lets
  connected devices easily and securely interact with Cloud applications and other
  devices.
- :doc:`Azure IoT Hub <azure-iot-hub>` -- a comprehensive collection of services
  and solutions designed to help you create end-to-end IoT applications on Azure.
