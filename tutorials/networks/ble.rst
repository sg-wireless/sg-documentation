BLE
===

The BLE (Bluetooth Low Energy) is a system feature of the SG module. There are
many applications including iBeacon, sensors, smartwatch, etc.

For more information, please refer to the
`MicroPython bluetooth class documentation <https://docs.micropython.org/en/v1.19.1/library/bluetooth.html>`_.

You may also want to look at the
`aioble library <https://github.com/micropython/micropython-lib/tree/master/micropython/bluetooth/aioble>`_
which provides a higher-level API for BLE operations.
